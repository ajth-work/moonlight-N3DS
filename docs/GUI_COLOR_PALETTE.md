# Moonlight GUI color reference

Color values sampled from the existing 256 x 128 Home Menu banner asset
`3ds/res/banner-gui16.png`:

- Main banner gray: `#555B63` (RGB 85, 91, 99). The background is textured and
  shaded, so nearby gray values also appear in the image.
- Main logo white: `#FEFEFE` (RGB 254, 254, 254). Some pixels are pure white,
  `#FFFFFF`, including antialiased edges.

Use these as the neutral gray and white references when matching Moonlight
banner colors in the GUI. They are sampled asset colors; they do not imply that
the GUI currently uses a flat gray background or pure-white-only artwork.
